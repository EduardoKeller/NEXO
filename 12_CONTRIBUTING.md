# CONTRIBUTING

Obrigado por contribuir com a plataforma NEXO.

Este documento define como alterações deverão ser realizadas.

---

# Filosofia

A qualidade do produto é prioridade.

Toda alteração deverá respeitar:

- Vision
- PRD
- Architecture
- Business Rules
- Design System
- Content Library

---

# Fluxo

1. Identificar necessidade.

2. Avaliar impacto.

3. Atualizar documentação.

4. Implementar.

5. Testar.

6. Revisar.

7. Registrar no CHANGELOG.

---

# Commits

Padrão:

feat:

fix:

refactor:

docs:

style:

test:

perf:

chore:

Exemplo:

feat: adiciona Evolution Engine

---

# Pull Requests

Todo PR deverá conter:

- objetivo;
- impacto;
- arquivos alterados;
- riscos;
- testes realizados.

---

# Código

Todo código deverá:

- utilizar TypeScript;
- possuir responsabilidade única;
- evitar duplicação;
- respeitar a arquitetura;
- seguir o Design System.

---

# IA

Alterações realizadas por IA deverão:

- respeitar toda documentação;
- informar decisões tomadas;
- justificar mudanças arquiteturais;
- nunca alterar regras de negócio sem aprovação.

---

# Documentação

Nenhuma funcionalidade poderá ser implementada sem documentação correspondente.

Sempre atualizar:

- PRD
- Business Rules
- Content Library
- Changelog

quando necessário.

---

# Objetivo Final

Garantir que toda contribuição preserve a qualidade, a consistência e a visão de longo prazo da plataforma NEXO.
