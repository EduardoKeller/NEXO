# 1. Objetivo

Este documento define as personas oficiais da plataforma NEXO.

As personas representam os principais grupos de usuários para os quais o MVP foi projetado.

Elas orientam decisões relacionadas a:

- Produto;
- UX;
- UI;
- Conteúdo;
- Comunicação;
- Avaliações;
- Plano de Evolução.

Toda nova funcionalidade deverá gerar valor para pelo menos uma das personas descritas neste documento.

---

# 2. Princípios

As personas não representam usuários específicos.

Elas representam padrões de comportamento observados em grupos semelhantes.

As personas poderão evoluir conforme dados reais forem coletados após o lançamento do MVP.

# 8. Diretrizes para Produto

Toda funcionalidade deverá responder:

- Resolve um problema real de pelo menos uma persona?
- É simples de utilizar?
- Gera valor rapidamente?
- Incentiva evolução?

Caso qualquer resposta seja negativa, a funcionalidade deverá ser reavaliada.

---

# 9. Diretrizes para UX

A experiência deverá ser:

- Conversacional.
- Objetiva.
- Simples.
- Acolhedora.
- Educativa.

O usuário nunca deverá sentir que está realizando uma prova.

A experiência deve parecer uma conversa guiada.

---

# 10. Diretrizes para Comunicação

Toda comunicação deverá:

- Explicar.
- Orientar.
- Incentivar.

Nunca deverá:

- Julgar.
- Culpabilizar.
- Assustar.
- Pressionar.

---

# 11. Critérios de Validação

As personas serão consideradas válidas quando:

✓ Representarem os principais públicos do MVP.

✓ Orientarem decisões de produto.

✓ Servirem como referência para UX e Conteúdo.

✓ Forem revisadas com base em feedbacks reais após o lançamento.

---

# 12. Evolução

Após o lançamento da versão 1.0, entrevistas, métricas e feedbacks dos usuários deverão ser utilizados para revisar ou expandir estas personas.

Nenhuma alteração deverá ser realizada apenas por opinião da equipe.
